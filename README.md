# 枕边主动降噪设备项目

## 项目概述
打造一款一键开机即用的枕边主动降噪设备，通过多麦克风阵列实时采集环境噪音，生成反向声波抵消鼾声、空调低频噪音与环境杂音，实现安静睡眠，整体方案低成本、可量产。

## 硬件配置
- **主控芯片**: STM32L496VGT6
- **拾音阵列**: 8 × MP34DT01 PDM 数字麦克风
- **音频功放**: MAX98357 双声道 I2S 数字功放
- **发声单元**: 2 × 4016 腔体喇叭
- **供电系统**: 内置可充电锂电池 + Type-C 充电 + 电源管理芯片
