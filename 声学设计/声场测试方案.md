# 声场测试方案

## 1. 测试目标

### 1.1 声场测试总体目标
1. **喇叭性能测试**：测试4016喇叭在腔体中的性能
2. **声场分布测试**：测试枕头区域的声场分布
3. **降噪效果测试**：测试反向声波降噪效果
4. **麦克风阵列性能测试**：测试麦克风阵列采集性能
5. **系统整体性能测试**：测试整个系统的声学性能

### 1.2 测试具体目标
1. **频率响应测试**：测试系统在不同频率下的响应
2. **声压分布测试**：测试声压在枕头区域的分布
3. **指向性测试**：测试系统声场指向性
4. **降噪深度测试**：测试降噪深度（噪声减少量）
5. **系统稳定性测试**：测试长时间工作的稳定性

## 2. 测试设备与工具

### 2.1 测试设备清单
#### 声学测试设备：
1. **声级计**：测量声压级
2. **音频分析仪**：分析音频信号特性
3. **示波器**：观测音频波形
4. **频率发生器**：产生测试频率信号
5. **频谱分析仪**：分析频率特性
6. **麦克风校准器**：校准测试麦克风
7. **数据采集系统**：采集测试数据

#### 环境模拟设备：
1. **枕头模拟器**：模拟真实枕头环境
2. **鼾声发生器**：模拟鼾声信号
3. **噪音发生器**：模拟环境噪音
4. **温度测量设备**：测量设备温度
5. **电源测量设备**：测量电源特性

### 2.2 测试软件工具
1. **音频分析软件**：音频信号分析
2. **数据采集软件**：采集测试数据
3. **信号处理软件**：处理和分析信号
4. **统计分析软件**：分析测试结果

## 3. 喇叭腔体声场测试

### 3.1 频率响应测试方案
#### 测试目的：
测试喇叭+腔体在不同频率下的声压级响应

#### 测试步骤：
```
频率响应测试步骤：
1. 准备测试设备：声级计、频率发生器、音频分析仪
2. 测试频率范围：50Hz-10kHz（重点50Hz-1kHz）
3. 测试频率间隔：50Hz间隔
4. 测试位置：距离喇叭10cm、20cm、30cm
5. 测试功率：0.5W、1W、2W
6. 记录测试结果：频率、声压级、相位等
```

#### 测试数据分析：
```
频率响应数据分析：
1. 绘制频率响应曲线
2. 分析低频响应性能
3. 分析高频响应性能
4. 分析谐振频率
```

### 3.2 声压分布测试方案
#### 测试目的：
测试枕头区域的声压分布情况

#### 测试方法：
```
声压分布测试方法：
1. 建立枕头区域测试网格
2. 网格点间距：5cm
3. 测试点数量：至少20个点
4. 测试频率：100Hz、300Hz、500Hz、800Hz、1kHz
5. 测试声压级：不同位置声压级
```

#### 枕头区域测试网格：
```
测试网格设计：
枕头的典型尺寸：长60cm，宽40cm
网格划分：6×4网格，共24个测试点
测试点坐标：网格点位置
测试高度：距离枕头表面3cm、5cm、8cm
```

#### 声压分布分析：
```
声压分布分析：
1. 绘制声压分布图
2. 分析声场均匀性
3. 分析声场方向性
4. 确定最佳声压位置
```

### 3.3 指向性测试方案
#### 测试目的：
测试喇叭声场的指向性特性

#### 测试方法：
```
指向性测试方法：
1. 以喇叭为中心建立测试圆形
2. 圆形半径：10cm、20cm
3. 测试角度间隔：15°
4. 测试频率：500Hz
5. 测量各角度声压级
6. 绘制指向性图
```

#### 指向性数据分析：
```
指向性数据分析：
1. 绘制指向性图
2. 分析声场扩散角度
3. 分析声场集中度
4. 确定最佳声场方向
```

## 4. 降噪效果测试方案

### 4.1 降噪原理测试
#### 测试目的：
测试反向声波降噪的基本原理

#### 测试步骤：
```
降噪原理测试步骤：
1. 产生测试噪声信号（100Hz正弦波）
2. 喇叭产生反向声波
3. 测量降噪前后的声压级
4. 计算降噪深度
5. 测试不同频率降噪效果
```

#### 测试数据分析：
```
降噪效果数据分析：
1. 计算降噪深度（dB）
2. 分析降噪频率范围
3. 分析降噪时间延迟
4. 分析降噪稳定性
```

#### 测试步骤：

```
鼾声降噪测试步骤：

```

#### 测试数据分析：
```
鼾声降噪数据分析：

3. 分析延迟对降噪的影响
```


## 5. 麦克风阵列声学性能测试

### 5.1 麦克风灵敏度一致性测试
#### 测试目的：
测试8个麦克风的灵敏度一致性

#### 测试方法：
```
麦克风灵敏度测试：
1. 使用标准声源产生测试声音
2. 测量每个麦克风接收的信号强度
3. 计算麦克风灵敏度差异
4. 校准麦克风灵敏度
```

#### 校准方法：
```
麦克风灵敏度校准：
1. 硬件校准：调整麦克风参数
2. 软件校准：通过算法补偿灵敏度差异
3. 综合校准：硬件+软件校准
```

### 5.2 麦克风阵列同步性测试
#### 测试目的：
测试麦克风阵列的同步性能

#### 测试方法：
```
同步性测试方法：
1. 产生同步声源信号
2. 采集所有麦克风的信号
3. 分析信号时间差异
4. 计算同步性误差
```

#### 同步性校准：
```
同步性校准：
1. 调整STM32 DFSDM配置
2. 优化采样同步机制
3. 算法补偿时间差异
```

### 5.3 麦克风阵列噪声识别测试

测试麦克风阵列的噪声识别能力

```
噪声识别测试：

3. 分析噪声方向识别准确率
```

#### 测试数据分析：

```
噪声识别数据分析：
```

## 10. 总结

声场测试方案需要全面测试喇叭腔体声学性能、麦克风阵列性能和系统降噪效果。通过实验室测试、模拟环境测试和真实环境测试三个阶段的系统测试，可以全面评估枕边降噪设备的声学性能。

测试的重点是：
1. 喇叭腔体的频率响应和声场分布
2. 麦克风阵列的灵敏度和同步性
3. 系统的降噪效果和稳定性

通过详细测试，可以发现问题，优化设计，确保设备性能达到设计要求。
