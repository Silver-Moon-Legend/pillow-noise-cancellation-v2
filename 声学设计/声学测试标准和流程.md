# 声学测试标准和流程

## 1. 声学测试概述

### 1.1 测试目的
建立枕边降噪设备的声学测试标准和流程，确保设备声学性能符合设计要求。

### 1.2 测试范围
1. **喇叭腔体声学测试**：测试喇叭腔体声学性能
2. **麦克风阵列声学测试**：测试麦克风阵列声学性能
3. **系统降噪效果测试**：测试系统降噪效果
4. **声场分布测试**：测试声场分布特性
5. **频率响应测试**：测试频率响应特性
6. **指向性测试**：测试声场指向性

### 2.2 声学性能标准

#### 喇叭腔体声学性能标准：
```
喇叭腔体声学性能标准：
1. 频率响应范围：50Hz-1kHz有效响应
2. 最大声压级：至少95dB（距离10cm）
3. 谐波失真：<2%
4. 声场均匀度：枕头区域内声压差异<3dB
```

#### 麦克风阵列声学性能标准：
```
麦克风阵列声学性能标准：
1. 灵敏度一致性：差异<1dB
2. 同步性误差：<0.1ms
3. 噪音识别准确率：>90%
4. 方向识别准确率：>85%
```

#### 系统降噪效果标准：
```
系统降噪效果标准：
1. 降噪深度：至少15dB（鼾声）
2. 降噪频率范围：50Hz-1kHz有效降噪
3. 延迟时间：<15ms
4. 稳定性：长时间工作降噪深度变化<3dB
```

### 2.3 声场测试标准

#### 声场分布标准：
```
声场分布标准：
1. 枕头区域声压均匀度：差异<3dB
2. 声场指向性：主要朝向枕头中心
3. 声场扩散角度：60°以内
```

#### 频率响应标准：
```
频率响应标准：
1. 频率响应范围：50Hz-1kHz有效响应
2. 频率响应均匀度：差异<5dB
3. 谐振频率控制：无明显谐振
```
