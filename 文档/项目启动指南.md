# 枕边降噪设备项目启动指南

## 第一步：环境准备

### 1. 安装必要的技能
```bash
# 已安装的技能
- signal-processing ✓
- stm32-cubemx ✓
- github ✓
 - tmux ✓
 
# 需要安装的技能
npx clawhub install embedded-dev  # 嵌入式开发
npx clawhub install python        # Python开发（需等待速率限制解除）
```

### 2. 创建项目目录结构
```bash
mkdir -p /root/.openclaw/workspace/projects/降噪设备
cd /root/.openclaw/workspace/projects/降噪设备

# 创建各专业目录
mkdir -p 算法
mkdir -p 嵌入式
mkdir -p 硬件
mkdir -p 声学
mkdir -p 文档

# 创建Git仓库
git init
```

### 3. 配置OpenClaw
将 `/root/.openclaw/workspace/profiles.yaml` 添加到OpenClaw配置中：
- 编辑OpenClaw配置文件
- 加入profiles配置

## 第二步：启动各专家Agent

### 1. 启动算法专家
```bash
# 使用signal-processing技能进行算法开发
openclaw agent start algorithm-expert
```

### 2. 启动嵌入式专家
```bash
# 使用stm32-cubemx技能进行STM32开发
openclaw agent start embedded-expert
```

### 3. 启动硬件专家
```bash
# 虽然没有专用技能，但可以使用通用能力
openclaw agent start hardware-expert
```

### 4. 启动声学专家
```bash
# 使用signal-processing技能进行声学分析
openclaw agent start acoustic-expert
```

## 第三步：项目分工

### 算法专家任务清单：
1. **研究PDM麦克风阵列信号处理**
   - 了解MP34DT01 PDM麦克风特性
   - 研究8路麦克风阵列的信号融合算法
   
2. **开发鼾声识别算法**
   - 分析鼾声特征（频率，持续时间，模式）
   - 设计鼾声分类器
   
3. **开发自适应降噪算法**
   - 研究自适应滤波技术（ANC算法）
   - 实现空调低频噪音消除
   - 环境杂音消除算法

4. **Python原型开发**
   - 使用Python模拟算法效果
   - 测试不同算法参数

### 嵌入式专家任务清单：
1. **STM32CubeMX配置**
   - STM32L496VGT6引脚配置
   - DFSDM接口配置（用于8路PDM麦克风）
   - I2S接口配置（用于MAX98357功放）
   - 电源管理配置

2. **驱动程序开发**
   - MP34DT01 PDM麦克风驱动
   - MAX98357 I2S功放驱动
   - 锂电池管理系统驱动

3. **算法移植**
   - 将算法专家的Python算法移植到C
   - 优化算法以适应STM32L496性能限制

4. **实时系统集成**
   - 实现实时音频处理流水线
   - 优化内存使用和性能

### 硬件专家任务清单：
1. **PCB设计规划**
   - STM32L496VGT6外围电路设计
   - 8路PDM麦克风阵列布局
   - MAX98357音频功放电路
   - Type-C充电电路设计

2. **元器件选型**
   - 锂电池选型（容量，尺寸）
   - 电源管理IC选型（BQ系列）
   - 4016腔体喇叭选型
   - 外围元器件清单

3. **原型制作**
   - 制作第一版原型板
   - 测试各个功能模块

### 声学专家任务清单：
1. **喇叭腔体设计**
   - 4016喇叭腔体声学优化
   - 考虑枕头放置的声学环境

2. **麦克风阵列声学优化**
   - 8路麦克风布局声学分析
   - 指向性优化

3. **声场测试**
   - 设计测试方案
   - 制定测试标准

## 第四步：协作流程

### 1. 项目管理
- 使用GitHub进行代码和文档管理
- 使用tmux进行协同调试
- 每日进度报告

### 2. 通信机制
- OpenClaw session_send进行跨agent通信
- 定期会议（使用腾讯会议技能）
- 文档共享（使用腾讯文档技能）

### 3. 版本控制
```bash
# 算法部分
git add algorithm/*

# 嵌入式部分
git add embedded/*

# 硬件部分
git add hardware/*

# 声学部分
git add acoustic/*

# 整体提交
git commit -m "项目进展"
```

### 第四阶段测试（声学验证）
