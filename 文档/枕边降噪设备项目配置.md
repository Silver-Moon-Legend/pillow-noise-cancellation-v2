# 枕边主动降噪设备项目配置指南

## 项目概述
打造一款一键开机即用的枕边主动降噪设备，通过多麦克风阵列实时采集环境噪音，生成反向声波抵消鼾声、空调低频噪音与环境杂音，实现安静睡眠，整体方案低成本、可量产。

## 硬件配置
**主控芯片**: STM32L496VGT6
**拾音阵列**: 8 × MP34DT01 PDM 数字麦克风
**音频功放**: MAX98357 双声道 I2S 数字功放
**发声单元**: 2 × 4016 腔体喇叭
**供电系统**: 内置可充电锂电池 + Type-C 充电 + 电源管理芯片

## 技能需求列表
根据项目需求，需要安装以下技能：

### 已安装的技能：
1. **stm32-cubemx** - STM32CubeMX配置，生成代码
2. **github** - GitHub协作和项目管理
3. **tmux** - 终端会话管理
4. **video-frames** - 视频处理（可用于音频可视化）
5. **weather** - 天气查询（环境参考）

### 需要安装的技能：
1. **signal-processing** - 信号处理算法开发
2. **embedded-dev** - 嵌入式开发技能
3. **python-scripting** - Python脚本开发（算法原型）
4. **audio-processing** - 音频处理工具
5. **matlab-simulink** - MATLAB仿真（可选）
6. **electronics-design** - 电子设计辅助（PCB设计）

## 团队角色配置
需要配置4种不同类型的agent，对应不同的工程角色：

### 1. 算法专家Agent
**职责**:
- 开发降噪算法（自适应滤波、麦克风阵列信号处理）
- 实现鼾声识别和分类
- 低频噪音消除算法
- 实时音频处理优化

**所需技能**:
- signal-processing
- python-scripting
- audio-processing

**Profile配置要点**:
- 精通信号处理理论和实践
- 熟悉Python和MATLAB算法开发
- 了解音频处理库（librosa, pydub等）

### 2. 嵌入式软件专家Agent
**职责**:
- STM32固件开发
- PDM麦克风驱动程序
- I2S音频接口配置
- 电源管理系统
- 实时操作系统集成

**所需技能**:
- stm32-cubemx
- embedded-dev
- github（代码管理）

**Profile配置要点**:
- 精通STM32系列MCU开发
- 熟悉CMSIS、HAL库
- 了解FreeRTOS或RTOS概念
- 掌握C/C++嵌入式编程

### 3. 硬件工程师Agent
**职责**:
- PCB设计和布局
- 元器件选型和测试
- 电源管理电路设计
- 麦克风阵列布局优化
- 腔体喇叭声学设计

**所需技能**:
- electronics-design（如果存在）
- github（文档协作）

**Profile配置要点**:
- 精通Altium Designer或KiCad
- 了解模拟电路和数字电路设计
- 熟悉电源管理IC（BQ系列等）
- 掌握声学基础理论

### 4. 声学工程师Agent
**职责**:
- 喇叭腔体声学设计
- 麦克风阵列声学优化
- 声场测试和校准
- 降噪效果评估

**所需技能**:
- audio-processing
- signal-processing（数据分析）

**Profile配置要点**:
- 精通声学理论和测量
- 了解喇叭设计和腔体优化
- 熟悉声场模拟软件

2. 使用**GitHub**进行代码和文档版本控制

4. **OpenClaw会话共享**进行跨agent沟通

## 工作流程分解

### 第一阶段：算法原型开发（1-2周）
- 算法专家：开发降噪算法原型（Python）
- 嵌入式专家：准备STM32开发环境
- 声学工程师：定义声学性能指标
- 硬件工程师：准备测试硬件

### 第二阶段：嵌入式实现（2-3周）
- 嵌入式专家：移植算法到STM32
- 算法专家：优化算法以适应实时处理
- 硬件工程师：制作测试电路板
- 声学工程师：测试声学效果

### 第三阶段：硬件集成（3-4周）
- 硬件工程师：完成PCB设计和制造
- 嵌入式专家：集成所有硬件组件
- 声学工程师：喇叭腔体最终设计
- 算法专家：最终算法调优

### 第四阶段：系统测试和量产准备（2-3周）
- 所有专家联合测试
- 性能优化和bug修复
- 量产准备和文档整理
